# Sales & Profitability Analytics Dashboard (Power BI)
#$ powerbi-sales-analytics-project
End-to-end Sales &amp; Profitability Analytics Dashboard built using Power BI to analyze sales performance, profit margins, regional trends, and product categories.

## 📌 Project Overview
This project focuses on building an end-to-end Sales & Profitability Analytics Dashboard using Power BI. The dashboard helps business users understand sales performance, profit margins, customer behavior, and regional trends for better decision-making.

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Excel / CSV Dataset

## 📊 Key Metrics Analyzed
- Total Sales
- Total Profit
- Profit Margin (%)
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top Products by Sales

## 🔄 Project Workflow
1. Imported and cleaned sales data using Power Query.
2. Created calculated measures using DAX.
3. Designed interactive dashboards with slicers and filters.
4. Analyzed trends and identified key business insights.

## 📁 Dataset
The dataset contains order-level sales data including order date, product category, region, sales amount, and profit.

## 🔍 Key Insights
- Technology category generates the highest revenue and profit.
- Certain regions show high sales but lower profit margins.
- Monthly sales analysis reveals seasonal trends.

## 🚀 Outcome
This project demonstrates skills in business analytics, data visualization, and storytelling using Power BI.
